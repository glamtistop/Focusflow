# 🌿 FocusFlow

A calm, ADHD-friendly focus tool. **🔒 Everything stays on your device** — nothing is uploaded, nothing is tracked, nothing is sold. No account, works offline.

## Features
- 📥 Zero-friction inbox (`n` from anywhere)
- 🐾 Choose-your-own buddy who cheers you on
- 🗓️ Visual planner with add-to-calendar (.ics) export
- 🌱 Habits, goals and a plain-language habit review
- 📲 Add to Home Screen on iPhone and Android
- ⏳ Focus buddy timer with on-device ambient sound
- 🌤️ Gentle check-ins that learn your rhythm
- 🧩 Break big projects into one tiny next action
- 🌙 Soft dark mode by default
- 🌤️ Weekly review in kind, plain words
- ⌨️ Keyboard shortcuts for everything (`?`)
- 🫧 Breathe button / `.` for instant calm
- 📄 Export to Markdown or plain text

## Run / deploy
It's static: `index.html` + `sw.js` + `manifest.webmanifest` + icons. No build step.
- Local: `python3 -m http.server` then open http://localhost:8000
- GitHub Pages: Settings → Pages → Deploy from branch → `main` / root.
